Proyecto: React ToDo (monorepo frontend + backend)  |  Project Keys: react-demo-todo (frontend) · todo-backend (backend)  |  Fecha: Agosto 2026

HerramientaVersiónVerificar

Windows: Si PowerShell bloquea npm, usa npm.cmd o Git Bash.

2. Instalar SonarQube Server

2.1 Con Docker (recomendado)

  1. Abre Docker Desktop y espera a que esté en ejecución.
  2. Ejecuta en terminal:
docker run -d --name sonarqube -p 9000:9000 sonarqube:latest
  1. Espera 1–2 minutos.
  2. Abre http://localhost:9000

2.2 Sin Docker

  1. Descarga SonarQube Community: sonarsource.com/products/sonarqube/downloads
  2. Extrae el ZIP (ej. C:\sonarqube).
  3. Ejecuta bin\windows-x86-64\StartSonar.bat.
  4. Abre http://localhost:9000

2.3 Detener / reiniciar (Docker)

docker stop sonarqube
docker start sonarqube

3. Primer acceso

  1. Ve a http://localhost:9000
  2. Usuario: admin — Contraseña: admin
  3. Cambia la contraseña cuando te lo pida.

4. Crear el proyecto en SonarQube

  1. Create → Manually
  2. Project key: react-demo-todo
  3. Display name: React Demo-todo
  4. Set Up → Locally
  5. Genera un token (nombre ej. cursor-local)
  6. Copia el token (squ_...). No se vuelve a mostrar completo.

5. Configurar el proyecto React

5.1 Instalar dependencias

cd C:\Users\cotit\OneDrive\Desktop\toDo
npm install

5.2 Crear sonar-project.properties

copy sonar-project.properties.example sonar-project.properties

Edita y pon tu token:

sonar.projectKey=react-demo-todo
sonar.projectName=React Demo-todo
sonar.host.url=http://localhost:9000
sonar.token=TU_TOKEN_AQUI
sonar.sources=src
sonar.tests=src
sonar.test.inclusions=**/*.test.js,**/*.test.jsx
sonar.exclusions=**/node_modules/**,**/coverage/**,**/*.test.js,**/*.test.jsx,**/test/**
sonar.javascript.lcov.reportPaths=coverage/lcov.info
sonar-project.properties está en .gitignore. No subas el token a Git.

6. SonarLint en Cursor

  1. Ctrl + Shift + X → instala SonarQube for IDE (SonarLint).
  2. Ctrl + Shift + P → conectar a SonarQube.
  3. URL: http://localhost:9000 + tu token.
  4. Project key: react-demo-todo

En .vscode/settings.json:

{
  "sonarlint.connectedMode.project": {
    "connectionId": "cursor-token",
    "projectKey": "react-demo-todo"
  }
}

10. Backend (Spring Boot): tests, cobertura y Sonar

El backend vive en backend/ y usa Maven a través del Maven Wrapper (mvnw / mvnw.cmd) — no necesitas Maven instalado. Tiene su propio proyecto en Sonar.

10.1 Datos del proyecto backend

CampoValor
Project keytodo-backend
Display nameToDo Backend

Ya configurados en backend/pom.xml. Sonar crea el proyecto solo, en el primer análisis.

10.2 Guardar el token como variable de entorno

setx SONAR_TOKEN "TU_TOKEN_AQUI"
setx solo aplica a procesos nuevos. Si el editor ya estaba abierto, reinícialo por completo (no basta con una terminal nueva). Verifica con echo $env:SONAR_TOKEN.

Puedes reusar el token del frontend si es un token de usuario (no uno de proyecto atado solo a react-demo-todo). Si da 401, genera uno nuevo.

10.3 Tests + cobertura (JaCoCo)

cd backend
.\mvnw.cmd clean test

Genera el reporte en:

backend/target/site/jacoco/index.html   ← visual
backend/target/site/jacoco/jacoco.xml   ← lo lee Sonar

10.4 Enviar el análisis a Sonar

cd backend
.\mvnw.cmd "org.sonarsource.scanner.maven:sonar-maven-plugin:sonar" "-Dsonar.host.url=http://localhost:9000" "-Dsonar.token=$env:SONAR_TOKEN"
Las comillas dobles en cada -D... son necesarias en PowerShell; sin ellas, los dos puntos de la URL rompen el parseo de argumentos.

Resultado en: http://localhost:9000/dashboard?id=todo-backend

10.5 Nota técnica: Java 25 y Byte Buddy

Si ves Java 25 (69) is not supported by the current version of Byte Buddy, es porque Mockito (vía Byte Buddy) aún no soporta oficialmente versiones muy nuevas de Java. Ya está resuelto en backend/pom.xml:

<argLine>@{argLine} -Dnet.bytebuddy.experimental=true</argLine>

12. Solución de problemas

ProblemaSolución
npm bloqueado en PowerShellUsa npm.cmd o Git Bash
Error de autenticación (frontend)Verifica token y que SonarQube esté en localhost:9000
SonarQube no arrancadocker logs sonarqube
SonarLint sin issuesRevisa conexión, project key, Reload Window
Cobertura 0% en SonarEjecuta test:coverage antes de sonar
401 Unauthorized en backendToken de proyecto (no de usuario) o variable vacía — revisa echo $env:SONAR_TOKEN
Error de resolución de plugin MavenEnvuelve cada -D... en comillas dobles en PowerShell
